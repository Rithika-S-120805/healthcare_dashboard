# Healthcare Analytics Dashboard

## Project Overview

This project is an interactive Healthcare Analytics Dashboard developed using Power BI.

The dashboard provides insights into:

- Patient demographics
- Appointment analytics
- Doctor performance
- Revenue analysis
- Treatment trends

## Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling
